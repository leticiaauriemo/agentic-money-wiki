# An AI Agent with a Wallet — Poncho (Merit Systems)

**Source:** [poncho.merit.systems](https://poncho.merit.systems/)

## What Poncho is

Poncho, built by Merit Systems, gives AI agents a wallet with configurable spending budgets to cross paywalls automatically. Instead of hitting a paywall and failing, an agent with Poncho pays micropayments on the fly.

## The problem it solves

Standard AI agents fail when they encounter paywalled content — LinkedIn profiles, premium news, Google Maps data, specialized databases. These failures degrade task quality and require human intervention.

## How it works

- Agent gets a wallet with a defined spending budget
- When agent encounters a paywall, Poncho pays automatically
- Costs: "just a few cents" per transaction; LinkedIn profile = $0.02; premium search = $0.02
- Alternative to $200+/month platform subscriptions — pay per actual use

## Target use cases

- **Lead generation** — agents researching prospect profiles via LinkedIn
- **Market research** — agents accessing premium data and news
- **Web research** — agents accessing content behind paywalls

## Cost control

Budget limits are the core control mechanism — agents cannot spend beyond the defined budget. This is a hard constraint at the wallet level, not a soft prompt-based guardrail.

## Relationship to Merit Systems

Poncho is one of Merit Systems' products, alongside AgentCash ($0.02 paywall access) and MPPscan/x402scan ecosystem explorers. Merit Systems is positioning as the "Google of the open agentic economy."
