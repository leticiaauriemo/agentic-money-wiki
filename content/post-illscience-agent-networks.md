# Post by @illscience — Agent Networks Open Questions

**Source:** [@illscience (Anish Acharya) on X](https://x.com/illscience/status/2050705776206115079), published 2026-05-01
**Author:** Anish Acharya, GP at a16z

## The open questions

Anish Acharya, reacting to Stripe Sessions 2026 and the John Collison / Claude Code dataset-purchasing demo, raised a list of structural open questions about agent networks:

1. **Traditional network effects:** Do they survive when participants are infinitely promiscuous (multi-homing by default)?
2. **Who owns discovery?** Parallel (Exa), Google, Moltbook, or an agent-native p2p network (like DNS)?
3. **Same properties as human networks?** Do machine networks have increasing returns to scale and an unassailable moat?
4. **What is ownable?** If agents can arbitrarily join/leave millions of networks, is there even a concept of proprietary supply or demand?
5. **Agent as semi-independent economic actor:** Agents act on behalf of humans, but is there a concept of agent dependency on humans vs. partial autonomy?
6. **Stripe's aggregator ambitions:** Stripe owns checkout experience and all human payment credentials. Will they try to become aggregator of supply and demand and intermediate the network?
7. **Network operator metrics:** How should network operators think about agent acquisition, retention, and churn?
8. **Web3 machine network analogies:** Similarities and differences?
9. **Reputation / identity / fraud:** Who handles this for machine-to-machine commerce?
10. **Micropayments:** Will this time finally be different?

## Structural implications

The "infinite promiscuity" problem is the core challenge for anyone trying to build network moats in the agent economy. Traditional network effects depend on switching costs and exclusivity; agents have neither by default.

The most durable moats suggested by this thread:
- **Reputation/routing quality** (not supply lock-in)
- **Settlement infrastructure** (Stripe is best-positioned here)
- **Identity/fraud handling** (unresolved)
- **Agent memory manipulation** (a new attack vector, not yet defended)
