# OpenClaw — Personal AI Assistant

**Source:** openclaw.ai product page
**URL:** https://openclaw.ai/

Product overview for OpenClaw — the open-source personal AI assistant by Peter Steinberger (@steipete) that triggered the "bottom-up autonomous agent" wave in early 2026.

## What it is

OpenClaw is a persistent, autonomous personal AI assistant that runs on the user's own machine (Mac, Windows, Linux) and operates through any chat platform the user already uses. It represents the first widely adopted "bottom-up" personal agent — as opposed to top-down enterprise deployments.

## Timeline

- **January 2026**: Launched; viral growth within days (19 days old at first major user wave)
- **January 30, 2026**: TechCrunch coverage: "OpenClaw's AI assistants are now building their own social network"
- **February 15, 2026**: Creator Peter Steinberger joins OpenAI; TechCrunch + The Verge coverage
- **March 7, 2026**: ClawCon meetup in NYC (The Verge: "serves optimism and lobster")

## Core capabilities

| Capability | Details |
|-----------|---------|
| **Chat platforms** | WhatsApp, Telegram, Discord, Slack, Signal, iMessage |
| **Persistent memory** | Remembers user preferences and context across sessions |
| **Browser control** | Browses web, fills forms, extracts data |
| **System access** | Read/write files, run shell commands, execute scripts |
| **Skills/plugins** | Community skills + self-written skills (can write its own) |
| **Models** | Anthropic, OpenAI, or local models |

## Self-modification

OpenClaw's defining capability: it can write and install its own skills. Users describe tasks; the assistant builds the automation.

> "It's a fact that claw can just keep building upon itself just by talking to it in discord is crazy." — @jonahships_

## Open-source model

- Installable via `curl -fsSL https://openclaw.ai/install.sh | bash`
- Context and skills stored on user's machine, not a walled garden
- Hackable install option
- Community-contributed skill library

## Significance for agentic payments

OpenClaw is the canonical bottom-up autonomous agent. Its user base — people giving AI assistants access to email, calendar, credit cards, and system files — is exactly the population that will drive demand for personal-agent payment infrastructure. Several users explicitly noted connecting financial accounts:

> "Came out of my shell and gave my @openclaw, Shelly, my credit card. Works amazing." — @jameskraus

The pattern: personal agents that control a computer will need controlled wallets and spend limits. Products like [[era]], [[slash]], and [[natural]] are building toward this user segment.
