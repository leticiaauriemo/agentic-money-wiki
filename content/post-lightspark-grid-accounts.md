# Post by @lightspark — Grid Global Accounts

**Source:** [@lightspark on X](https://x.com/lightspark/status/2049217085075501504), published 2026-04-28

## What launched

**Grid Global Accounts** — AI agent bounded delegation. "The first account built for agents to transact safely."

Lightspark's answer to the hard constraint problem for agent payments: give each agent its own operating pocket with enforced limits.

## Features

- **Funded, scoped, and fully auditable** — agent has its own account with defined funds
- **Spending limits and approved payees enforced at the wallet level** — not at the prompt or instruction layer (hard architectural constraints, not soft guardrails)
- **Revocable instantly, any time** — human can cut off agent access immediately

> "The agent works within the boundaries you set. You never lose control."

## Significance

This is a direct implementation of the principle established by Ramp Labs' research: **hard architectural spending constraints are mandatory** because soft guardrails systematically fail. Lightspark is enforcing limits at the wallet level, not the instruction level.

Positions Lightspark as infrastructure for the bounded delegation problem — a gap in MPP and x402 (which are payment protocols, not delegation frameworks).
