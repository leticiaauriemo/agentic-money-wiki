# NEAR Protocol

**One-line:** Layer-1 blockchain best known in the agentic payments space for NEAR Intents — a universal liquidity protocol enabling cross-chain swaps across 31 chains and 125+ assets for DeFi, AI agents, and end users.

## What they're building

NEAR Protocol is a sharded, proof-of-stake Layer-1 blockchain. Its most relevant product for agentic payments is **NEAR Intents** — a universal liquidity protocol that abstracts cross-chain complexity for applications and AI agents.

## NEAR Intents

**URL:** intents.near.org

| Metric | Value |
|--------|-------|
| All-time volume | $17B+ |
| Chains supported | 31 |
| Assets | 125+ |

**How it works:**
- Applications/agents express an *intent* (desired outcome) rather than specifying the exact execution path
- NEAR Intents routes execution optimally across chains
- Settlement in milliseconds with near-zero slippage

**Architecture:**
- Single API integration → liquidity across all 31 chains
- Optimized routing for fast, predictable-fee execution
- Verifiable infrastructure with no single points of failure

**Target users:** DeFi applications, AI agents, end users

## Relevance to agentic money

NEAR Intents is positioned as the universal liquidity layer for agents that need to transact across chains without managing per-chain integrations. The intent model is conceptually aligned with how agents work: express a goal, delegate the execution.

Compared to other rails:
- **x402** — single-chain micropayments (Base/Ethereum)
- **MPP** — session-based payments (Tempo Mainnet)
- **NEAR Intents** — cross-chain liquidity routing (31 chains)

These are complementary, not competing: x402/MPP handle the payment authorization layer, NEAR Intents handles the liquidity/settlement routing layer.
