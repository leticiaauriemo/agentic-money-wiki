# Shoal Signal Ep. 6 — Autonomous Agentic Commerce: Micropayments, AgentCash, x402 & MPP

**Source:** @Shoalresearch on X, 2026-05-14 (podcast announcement)
**URL:** https://x.com/Shoalresearch/status/2055009805346263249
**Watch:** https://youtu.be/vVmyBfGqM7Q
**Guest:** @shafu0x (founding engineer, Merit Systems)

## Topics covered

1. **Why credit cards break under sub-cent API calls** — fixed fee component makes any transaction below ~$5 uneconomical
2. **x402/MPP give Claude superpowers** — agents can access prospecting tools (Apollo, Parallel, Exa) via x402 micropayments without API keys
3. **Why stablecoins, not credit cards?** — permissionless, sub-cent fees, 24/7 settlement, programmable authorization scopes
4. **Supply side: APIs going agent-native** — providers opting into micropayments; per-call pricing unlocks new distribution
5. **x402scan, routing, and discovery** — how agents find and pay for services
6. **Failed calls, refunds, and trust** — the trust gap in machine commerce
7. **Agent-to-agent commerce** — "the missing use case nobody can actually name" (2026-05-14 context)
8. **Death of ads via per-request payments** — x402 quietly kills ad-supported content model for agent-facing APIs
9. **Rebranding away from "crypto"** — shafu stopped using the word crypto in sales calls; focusing on stablecoins as USD rails
10. **Where the alpha is** — picks-and-shovels infrastructure

## Key quote

@superfluid.eth in comments: "credit cards were designed for humans buying coffee, not autonomous systems making thousands of API calls"
