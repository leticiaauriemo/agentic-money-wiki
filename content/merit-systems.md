# Merit Systems

**One-line:** Building the discovery and payment layer for the open agentic economy — creator of MPPscan, x402scan, and AgentCash, positioning as the "Google of open agentic commerce."

## What they're building

Merit Systems operates at the intersection of discovery and payments for AI agents:

**MPPscan** — the ecosystem explorer and analytics dashboard for the Machine Payments Protocol (mppscan.com). Tracks agents, servers, transactions, volume.

**x402scan** — marketplace and explorer for x402 ecosystem (x402scan.com). 293 active merchants, 559 unique registered buyers, 167.96M+ ecosystem transactions.

**AgentCash** — "one balance, access to every API on the internet." Discovery and payment platform for agents:
- 524,289+ API calls made by agents
- 83,279+ installs
- 439+ endpoints available
- 15+ partners
- $100,000 being distributed to first users ($25 onboarding credit)
- Partners include: StableEnrich, StableStudio, StableSocial, StableEmail, StableUpload, StableTravel (70 routes for flights, hotels, activities)

**Poncho** — consumer product; agent wallet for crossing paywalls. Uses x402 to pay $0.02 per premium profile access on LinkedIn, Apollo, Google Maps, Whitepages etc.

## Relevance to agentic money

Merit Systems is the picks-and-shovels play for both x402 and MPP — building the aggregation layer that agents use to discover and pay for services regardless of which protocol wins. Analyst @onchainlu identified Merit as a wildcard positioned as the "Google of the open agentic economy" if open protocols win over curated marketplaces.

**Key insight:** Merit builds the discovery layer (AgentCash, x402scan, MPPscan) and the consumer interface (Poncho). If discovery is the largest unsolved problem in agentic commerce (as the Machine Economy 2030 analysis argues), Merit is in the best position of any open-protocol player.
