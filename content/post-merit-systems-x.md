# Post by @merit_systems: Tempo Mainnet Is Live

**Source:** [X post by @merit_systems](https://x.com/merit_systems/status/2034257387482189890)
**Published:** 2026-03-18

## What was announced

**Tempo Mainnet launched** — MPP (Machine Payments Protocol) open standard is now live on mainnet. This marks the transition from testnet/preview to production.

## Onboarding infrastructure

- **MPPscan** — ecosystem explorer to track usage metrics and popular resources
- **AgentCash** — unified balance tool for accessing MPP APIs
- **New user incentive** — up to **$25 USDC** on Tempo Mainnet for onboarding
- **Public RPC endpoints** available
- **Tempo CLI** — command-line interface for interacting with Tempo

## Key message

"One balance, access to every API on the internet" — AgentCash's positioning as the MPP onboarding ramp.

## Notable comment from thread

A reply flagged a potential security concern: CLI-integrated explorers create command execution pathways that could introduce code injection risks. This is an early warning about security challenges specific to agent payment infrastructure.

## Significance

March 18, 2026 is the confirmed Tempo Mainnet launch date. This is the authoritative source for that date.
