# Mastercard

**One-line:** The first major card network to execute live, end-to-end AI agent-initiated payments at scale across multiple geographies, using its Agent Pay infrastructure on existing rails.

## What they're building

Mastercard's **Agent Pay** platform enables AI agents to initiate and complete payments on behalf of cardholders using existing Mastercard network infrastructure — no new rails or credentials required. The system combines three components: **Agentic Tokens** (agent-bound credentials), **Payment Passkeys** (authentication), and **Verifiable Intent** (co-developed with Google — tamper-resistant records of what users authorized). The **Agent Pay Acceptance Framework** governs how merchants participate.

## Relevance to agentic money

Mastercard is the most operationally advanced of the major card networks in agentic payments. While Visa is still in developer tools / pilot phase, Mastercard has completed live end-to-end transactions in three regions. It is proving that agentic payments can run on existing rails with existing issuers — no crypto required.

## Funding & traction

Public company. Key milestones:
- **2026-02-27:** Europe's first live AI agent payment, with [[santander]] (within Santander's regulated payment infrastructure)
- **2026-02-27–03-23:** Live transactions across Latin America and the Caribbean — 16+ banks and processors participating (BAC, Banco Itaú, Bancolombia, Santander, Davivienda, Dock, Evertec, Pomelo, Oriental Bank, and more)
- **2026-04 (approx.):** Live in Singapore and Malaysia; additional ASEAN markets to follow
- **BVNK acquisition:** valued at up to $1.8B (expanding digital assets capabilities)
- **Nearly 100% of issuers in Latin America** already enabled with Mastercard's agentic token technology

## Products / offerings

- **Mastercard Agent Pay** — full agentic payment platform
- **Agentic Tokens** — credentials bound to a specific agent, not reusable
- **Payment Passkeys** — authentication mechanism for agent-initiated transactions
- **Verifiable Intent** — cryptographic record of user authorization (co-developed with [[ap2]] partner Google)
- **Agent Pay Acceptance Framework** — merchant-side integration standard
- **Mastercard Agent Toolkit / Virtual C-Suite / Agent Suite** — developer tooling
