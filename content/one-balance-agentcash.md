# One Balance, Access to Every API on the Internet — AgentCash

**Source:** [agentcash.dev](https://agentcash.dev/)

## What AgentCash is

AgentCash is a unified payment layer allowing AI agents to access paywalled APIs and data without API keys, accounts, or subscriptions. One stablecoin balance grants access to 439+ endpoints across multiple services.

## Traction (as of April 2026)

- **524,289+** API calls made
- **83,279+** installs
- **439+** endpoints available
- **15+** service partners

## Service categories

| Service | Routes | Provides |
|---------|--------|----------|
| StableEnrich | 30 | People/company enrichment (Apollo, Exa, Firecrawl, Clado, Google Maps) |
| StableStudio | 28 | Image/video generation |
| StableSocial | 45 | Social media data |
| StableEmail | 24 | Transactional email |
| StableUpload | 10 | File uploads |
| StableTravel | 70 | Travel search |

## Supported agent platforms

Works with: Claude Code, Cursor, Codex, Claude Desktop, Gemini CLI, Poncho, OpenClaw

## Payment model

Uses x402 protocol for micropayment settlement. Agents discover and pay for services automatically — no pre-registered accounts, no API key management.

## Onboarding incentive

New users receive up to $25 USDC bonus (conditioned on relevance to agentic commerce use case).

## Relevance to agentic money

AgentCash is a live implementation of the "one wallet, all the internet" model. With 83K+ installs and 524K+ API calls, it demonstrates real agent-to-API payment flows in production, not just pilots.
