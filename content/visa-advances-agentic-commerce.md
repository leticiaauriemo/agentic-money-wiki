# Visa Advances Agentic Commerce with Developer Updates

**Source:** [Visa Corporate](https://corporate.visa.com/en/sites/visa-perspectives/innovation/visa-mcp-server-agent-acceptance-toolkit.html)
**Published:** 2025-04-09

## Two developer releases

### 1. Visa MCP Server (pilot)
- Connects AI agents directly to Visa Intelligent Commerce APIs via Model Context Protocol
- Reduces integration time from "days or weeks" to "hours"
- Secure: enforces all policies and role-based access controls by design
- Available as self-hosted npm package for JavaScript developers

### 2. Visa Acceptance Agent Toolkit (pilot)
- Enables non-technical users (and agents) to trigger commerce workflows via plain-language prompts
- Supports Invoice and Pay By Link workflows
- Example: "Create an invoice for $100 for John Doe, due Friday" → agent generates payment link automatically

## Core message

MCP eliminates the need for hand-coded API calls and complex authentication when building agent-commerce integrations. Visa is reducing the friction to zero for developers building on Visa rails.

## Relevance to agentic money

This confirms Visa's strategy: be the infrastructure layer, not the consumer-facing experience. By releasing an MCP server, Visa positions itself as natively compatible with any MCP-enabled AI agent (Claude, GPT, Gemini, etc.) without custom integrations per model.
