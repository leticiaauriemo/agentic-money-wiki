# a16z Thread: Agent-Driven Micropayments and API Monetization

**Source:** [a16z on X](https://x.com/a16z/status/2044498546532237323)
**Published:** 2026-04-15
**Context:** Quote from Aaron Levie at Daytona Compute Conference

## Core message

Agent-driven micropayments could create a "completely different business model for the internet." A penny per transaction starts to make sense at 100 million agents tapping proprietary data.

## The subscription model collapses

Flat monthly rates convert to per-action economics. APIs that previously required developer subscriptions ($99–$999/month) become accessible via per-agent-call micropayments. Revenue scales with agent volume rather than human seat count.

## Infrastructure mentioned

- **Coinbase agentic wallet** — payment execution layer
- **Filecoin** — storage with verifiable provenance
- **x402 on Base** — payment rail

## Flywheel thesis

AI agents paying AI agents for compute creates a flywheel nobody modeled in 2015. The first-order effect (humans using agents) creates second-order effects (agents using agents for sub-tasks) that multiply payment volumes.
