# Introducing Agentic.Market: The Homepage of the Agent Economy

**Source:** @Nick_Prince12 (Coinbase), 2026-04-20
**URL:** https://x.com/Nick_Prince12/status/2046262146523107342

Launch announcement for Agentic.Market, Coinbase's discovery and reporting marketplace for the x402 ecosystem.

## Context

At launch, the x402 ecosystem had:
- **165M+ transactions**
- **~$50M in volume**
- **~100K services**
- **480K+ agents** as buyers

Despite this scale, discovery remained fragmented — builders relied on word-of-mouth to find services.

## What Agentic.Market provides

**For Builders:** A single place to evaluate and instantly use x402-enabled services.

**For Providers:** Distribution to agent buyers via curation, enriched listings, and real usage data.

**For Agents:** A machine-readable discovery layer agents can query at runtime.

**For Enterprises:** A polished, data-rich view of the agentic commerce landscape.

## Core features

- **Zero Friction:** No API keys, accounts, or logins required
- **Semantic Search:** Across thousands of services in categories: Inference, Data, Media, Search, Social, Infrastructure, Trading
- **Live Performance Metrics:** Real-time TPV, transactions, unique buyers/sellers, average transaction value per service
- **Detailed Service Cards:** Everything needed to purchase and have an agent execute
- **Automatic Indexing:** Services are picked up on first use

## Dual interface design

Two distinct access modes:

1. **Web Interface** — filterable UI for humans to browse and evaluate services
2. **MCP Endpoint** — programmatic access for AI agents to search, filter, and integrate new capabilities at runtime without human involvement

Quick start: `npx skills add coinbase/agentic-wallet-skills`

## Significance

Agentic.Market centralizes what had been a fragmented ecosystem. However, the auto-indexing of any x402 service (including third-party unauthorized wrappers) created the governance controversy documented in [[who-authorized-this-x402]].
