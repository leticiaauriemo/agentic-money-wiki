# Machine Economy 2030

**Source:** [X thread by @onchainlu, 2026-03-30](https://x.com/onchainlu/status/2038618354009653691)
**170 companies mapped; ~80 distilled**

## Core thesis

By 2030, AI agents will be the primary way people interact with the internet. The agentic economy has five layers: Interface, Agents & Accounts, Payments, AI Engine, and Infrastructure. Value concentrates in whoever controls interface (shapes what agents buy), payments (sits in money flow), and compute (hosts the agents).

**The key question isn't will agents transact — it's which layer captures value.**

## Concrete 2030 scenario: Joe in Vermont

24-year-old fintech consultant with a personal agent named Nexus. Overnight:
1. Agent trims equity position 15% using satellite data + earnings sentiment
2. Sales subagent sources 200 leads, enriches each for $0.002/lead, books 3 meetings — total cost: **$0.24** (vs. $200/month SaaS lead gen)
3. Ops subagent benchmarks 6 hosting providers, negotiates new host, runs full migration — fractions of a cent

**Total cost to Joe: $0.67 across hundreds of transactions.** Adds $5 via Apple Pay (auto-converts to stablecoins, never sees blockchain or wallet).

## Scale math

- 1 billion knowledge workers globally; 88% already using AI at work
- Mid-size company (500 employees): potentially 100,000+ agent transactions/day
- **If 60% of knowledge workers spend $3–5/day by 2030: $800B–$1.4 trillion/year in individual agent commerce alone**
- Enterprise spend (commercial agents) will dwarf individual spend

## Why traditional internet breaks

Built for humans: rate limits, CAPTCHAs, API keys filter non-human activity; economics depend on ad revenue from human eyeballs. With proliferation of agents: more traffic, fewer eyeballs, servers subsidized by ads face orders-of-magnitude more requests from users who can't be advertised to. Solution: **pay-to-crawl, pay-to-access, pay-to-use**.

## Supply-side reality check (April 2026)

Most early x402 activity was developer testing and gaming/leaderboard behavior. "Qualified sellers" (≥2 real transactions, ≥2 unique buyers):
- October 2025: **<100**
- April 2026: **>4,000** (40x growth)

Still not a real economy yet — but the trajectory is clear.

## The five-layer stack and winners

**Interface layer (biggest leverage):**
- Apple — devices deeply embedded; Siri + agent control = billions of transactions
- Google — hard transition (cannibalizes ads) but best personal data corpus
- **Merit Systems** — wildcard; building discovery (AgentCash, x402scan, MPPscan) + consumer interface (Poncho); "Google of open agentic economy" if open wins

**Payments:**
- **Stripe/Tempo** — best positioned for machine-native; developer ecosystem + merchant network
- **Circle** — scales with agentic economy; USDC most widely accepted
- **Visa** — will adapt; cards remain + stablecoins settle underneath (invisible to user)

**The key protocol debate:**
- **Curated marketplaces** (OpenAI/Stripe ACP, Google UCP, Visa TAP) — walled gardens, higher trust, lower flexibility
- **Open protocols** (Coinbase x402, Merit Systems, Orthogonal) — permissionless, long-tail, composable
- **Open won last time** (web vs. AOL)

## Key stats

- Claude Code: 4% of GitHub commits (135,000+/day); projected 20%+ by end 2026; 42,896x growth in 13 months
- Inference cost: $20/M tokens (late 2022) → $0.05/M tokens (early 2026) — **600x decline**
- Open-weight models: 1.7% gap to closed models on some benchmarks
- AWS: ~30% global cloud infrastructure; Cloudflare: in front of 20% of all websites
- Card network floor: $0.03–$0.04 + 2.3–2.9% interchange
