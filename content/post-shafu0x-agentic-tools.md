# Post by @shafu0x — Agentic Commerce Without API Keys

**Source:** @shafu0x (founding engineer, Merit Systems) on X, 2026-05-23
**URL:** https://x.com/shafu0x/status/2058237155269296151

## Key claim

> "Agentic Commerce is real! My agent has access to all of this without a single API key."

The post lists 60+ services accessible through x402/MPP micropayments — including Firecrawl, Parallel, Tavily, Exa, Apify, Diffbot, Browserbase, Apollo, CoinGecko, Etherscan, Supabase, and many more.

## Significance

This is production evidence that the x402/MPP "no API key" model is working. An agent can access web scraping, data enrichment, AI models, social media data, job boards, maps, financial data, and crypto infrastructure — all via micropayments, no subscription or key management required.

This demonstrates the "headless merchant" model at scale: APIs registering on x402scan and MPPscan, charging per-call in USDC. The ecosystem is real enough that a single agent can access 60+ services without traditional authentication.

## The x402scan reference

The post includes x402scan in its list alongside Supabase and Stablebase — suggesting x402scan itself is a discoverable/queryable service in the ecosystem, not just a dashboard.
