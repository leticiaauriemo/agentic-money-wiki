# The Missing Infrastructure for AI Agents: 5 Ways Blockchains Can Help

**Source:** [a16z Crypto on X](https://x.com/a16zcrypto/status/2046243550715945367)
**Authors:** @cc_crowley, @ccatalini, @ahall_research, @liz_harkavy, @nlevine19, @psneville
**Published:** 2026-04-20

## Core argument

The bottleneck for the agent economy is **identity, not intelligence**. Blockchains solve five critical infrastructure gaps that neither existing cloud nor traditional finance addresses.

## The 5 gaps

### 1. Portable identity (Know Your Agent)
Non-human identities already outnumber human employees in financial services by ~100:1. Agents need portable, verifiable identities not tied to any single platform. On-chain identity (ERC-8004) enables this.

### 2. Governance guarantees
Agents operating AI-run systems need cryptographic constraints — not just policy documents. On-chain execution and smart contract constraints make agent behavior verifiable and auditable.

### 3. Alternative settlement (headless merchants)
A new merchant class is emerging: "headless" merchants (no frontend, just server + endpoints + price per call). Traditional payment processors won't underwrite them. Stablecoins are permissionlessly programmable without merchant agreements.

### 4. Verifiable provenance and audit trails
As AI systems scale, manual inspection becomes impossible. Blockchain-based audit trails replace human review with cryptographic proof — essential for regulated industries.

### 5. Scoped delegation and user control
Smart contracts enable users to grant agents specific, bounded authority. MetaMask Delegation Toolkit, AgentKit, AgentCash implement this at the application layer.

## Key insight: verification becomes the new constraint

When execution becomes abundant and cheap, **verification** becomes scarce. The question is whether agent economy infrastructure will be designed for transparency and user control, or built on centralized systems.
