# Peter Steinberger

**Role:** Creator of OpenClaw; joined OpenAI (February 15, 2026)
**X:** @steipete
**Relevance:** Created the first widely adopted bottom-up personal AI agent, triggering the consumer-agent wave that is driving demand for personal-agent payment infrastructure.

## What he built

**OpenClaw** (January 2026) — open-source personal AI assistant that runs on a user's own machine, accessible via WhatsApp/Telegram/Discord/Signal/iMessage. Characterized by:
- Persistent memory (context persists 24/7)
- Self-modification (can write and install its own skills)
- Full system access (files, shell, browser)
- Privacy-first (context stays on user's machine)
- Hackable install option

Launched January 2026; viral growth within days. TechCrunch covered it on January 30, 2026: *"OpenClaw's AI assistants are now building their own social network."*

## Views / positions

The OpenClaw product reflects a specific philosophy: personal AI should run on the user's own hardware, be fully hackable, and not be locked to a single provider. Several users noted this explicitly:

> "A megacorp like Anthropic or OpenAI could not build this. Literally impossible with how corpo works." — @Dimillian

## Significance for agentic payments

Steinberger created the first product where large numbers of non-technical consumers gave an AI agent:
- Access to their email
- Control of their calendar
- Their credit card
- Access to their files and system

This user base — people already comfortable with agents controlling financial access — is the natural early adopter segment for products like [[era]], [[slash]], [[natural]], and [[meow-technologies]]. The OpenClaw wave is direct evidence that consumer appetite for autonomous personal agents is real and large.
