# Era

**One-line:** SEC-regulated personal finance MCP that lets Claude, ChatGPT, or any AI autonomously manage money (transfers, portfolio adjustments, overspending fixes) without constant user instruction.

## What they're building

Era provides a personal MCP (Model Context Protocol) layer for memory and money. The platform:

- Enables autonomous money management: transfers, overspending corrections, portfolio adjustments
- Works across any LLM (Claude, ChatGPT, others) as a cross-platform layer
- Acts while the user is not engaged — not just when prompted

## Key concept: Agency vs. Agents

Era distinguishes between:
- **Agents** — AI that acts on demand when you prompt it ("human in the loop")
- **Agency** — AI that acts autonomously while you're not engaged ("human on the loop")

Era aims for the second: money management as a continuous background process, not an on-demand tool.

## Regulatory status

SEC-regulated for investment functionality — Era has navigated the regulatory requirements for autonomous investment management, which is a meaningful differentiator for a startup in this space.

## Relevance to agentic money

Era represents the consumer-facing agentic banking use case: a personal financial agent that manages real money. SEC registration distinguishes it from tools that only automate viewing/reporting. Open question: what rails does Era use for execution (card, ACH, stablecoin)?
