# Dimitar Dimitrov

**Role:** Founder and Managing Partner, Accedia (European AI & Custom Software Development)
**Relevance:** Authored the "three gaps" framework for bank readiness in agentic payments (Forbes, 2026-04-21). Practitioner perspective from working with banks on AI infrastructure.

## Views / positions

Banks are architecturally unready for agentic payments because every layer was built assuming a human initiates every transaction. The three gaps: fraud detection, authentication, and API throughput. See [[bank-readiness-agentic-payments]] for the full framework.

## Actions taken

- Published framework for bank agentic readiness (Forbes Technology Council, 2026-04-21)
- Cited work with a U.K. bank building a separate fraud detection model for non-human transaction patterns
