# NEAR Intents — The Universal Liquidity Protocol

**Source:** intents.near.org
**URL:** https://intents.near.org/

Product overview for NEAR Intents, the cross-chain liquidity protocol on the NEAR Protocol.

## What it is

NEAR Intents is a universal liquidity protocol that powers cross-chain swaps, unified liquidity access, and order execution for DeFi applications, AI agents, and end users — abstracting away cross-chain complexity.

## Key stats

- **$17B+ all-time volume**
- **31 chains** supported
- **125+ assets**

## How it works

Novel transaction architecture that:
1. User/agent expresses an **intent** (what they want to accomplish) rather than specifying the exact path
2. NEAR Intents routes execution optimally across chains
3. Settlement happens in milliseconds with near-zero slippage

## Core properties

| Property | Description |
|----------|-------------|
| **Instant execution** | Cross-chain swaps in milliseconds via optimized routing |
| **Predictable fees** | Low and known in advance |
| **Verifiable infrastructure** | No single points of failure; transparent execution |
| **Unified liquidity** | Single API integration = access to all 31 chains |

## Agent relevance

NEAR Intents is explicitly designed for AI agents as a primary user category alongside DeFi apps and end users. The single-API model means agents don't need to manage separate integrations per chain — they express what they need, and NEAR Intents handles routing.

This positions NEAR Intents as potential universal liquidity layer for agent-initiated cross-chain payments, complementary to rails like [[x402]] (single-chain micropayments) and [[mpp]] (session-based payments).
