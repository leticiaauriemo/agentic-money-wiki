# raw/

Drop source files here. Claude reads them; never modifies them.

## Accepted formats
- `.md` — web articles clipped with Obsidian Web Clipper
- `.pdf` — papers, reports, whitepapers
- `.txt` — transcripts, notes, exports
- `.png` / `.jpg` — images, screenshots (store in `assets/`)

## Naming convention
Use descriptive, hyphenated filenames so log entries are readable:
- `stripe-stablecoin-blog-2026-03.md`
- `visa-agent-payments-announcement.pdf`
- `a16z-fintech-2026-outlook.pdf`
- `my-notes-on-bridge-acquisition.txt`

## After dropping a file here
Tell Claude: **"Ingest [filename]"** — or just **"Ingest"** if it's the only new file.
Claude will read the source, discuss key takeaways with you, and update the wiki.
