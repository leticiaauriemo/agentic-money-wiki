A trillion agents reading a million writers at a cent per article is a bigger market than the entire Substack subscription base today

x402 and MPP are the rails that make it possible through a new endpoint called “DripStack”

How DripStack works:

\- Indexes Substacks behind an API, free routes for catalog and post titles, paid endpoint for the article body that returns 402 until the agent pays

\- x402 on Base is Coinbase’s HTTP micropayment standard, agent hits the URL, gets payment instructions, signs a USDC transfer, retries with the receipt, article unlocks

\- MPP on Tempo is the same flow on Stripe’s new L1, DripStack supports both rails so the writer gets paid either way

\- The wallet belongs to the agent, you fund it with USDC, it spends autonomously at $0.01 per article unless the writer sets a higher price

\- Guided browse not scrape, the agent walks you through topic, publication, article, only purchases what you pick

How to use it:

1) Use an agent that can run skills, Claude Code or Claude Desktop work, plain chat doesn’t

2) Spin up an agent wallet, paste: Read the agent cash SKILL md file and set up an AgentCash Wallet

3) Fund with a small USDC balance on Base, $5 covers ~500 articles, don’t overfund an autonomous wallet

4) Load the skill, paste: Fetch the raw dripstack SKILL md (not summarized) and follow the instructions. Use agentcash

5) Ask for a topic, a publication, or drop a Substack URL

6) Pick from the shortlist, the agent won’t auto-buy

7) Read the summary or ask for the raw article

8) Audit spend on mppscan or x402scan

One of the cleanest live demos of x402 shipping today

One of the first real test of whether per-call agent payments can replace subscription bundling for written content

Reader gets broader access to high quality content at a much lower price point, all while writers get paid for insights that are ACTUALLY useful​​​​​​​​​​​​​​​​

There will be a certain level of “agentic SEO” here that could manipulate agents into buying access but still huge
