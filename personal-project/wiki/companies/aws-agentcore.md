## What they're building

AgentCore provides memory, identity, tool access, and orchestration primitives for agents running inside a customer's AWS environment. It is infrastructure for a company running its own agents, not a marketplace for hiring external ones.

## Relevance to this startup

The most important positioning question. AgentCore solves "how do I run my agents reliably?" We solve "how do I hire trusted specialists I don't own?" Different buyer, different problem. Risk: if AWS adds cross-org routing and a vetted marketplace on top of AgentCore, that compresses our window.
