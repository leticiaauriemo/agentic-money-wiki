# x402 Protocol

**Type:** payment protocol (HTTP 402-based)
**One-line:** A protocol for machine-native micropayments using HTTP 402 — allows AI agents to pay for services programmatically without human intervention per transaction.

**TODO: expand**

## How it works

x402 leverages the HTTP 402 "Payment Required" status code (historically unused) to enable machines to negotiate and settle payments inline during an API call. An agent requests a resource, receives a 402 with payment terms, pays via crypto rail (typically stablecoin on Base), and receives access — all without a human in the loop.

## Settlement speed & cost

Sub-second on L2 (Base). Near-zero transaction cost at scale. Designed for high-frequency, low-value agent workflows.

## Who controls it

Coinbase led the x402 design; open spec. Coinbase Agentic.market uses x402 as its payment rail.

## Agent-friendliness

Very high — designed specifically for autonomous machine payments.

## Our relationship

x402 is a candidate payment rail for specialist payments in our platform. Alternatively, Stripe MPP provides a more traditional but also machine-native option. The choice depends on client risk appetite (crypto vs. fiat rails).
