# Agent-to-Agent Protocol (A2A)

**Type:** open protocol (Google-led)
**One-line:** Google's open protocol for direct agent-to-agent communication — complementary to MCP, focused on the interaction pattern between agents rather than tool invocation.

**TODO: expand**

## How it works

A2A defines how one agent communicates tasks and results to another agent directly. Where MCP is about tools/resources, A2A is about agent delegation and coordination. Together they form a fuller agent communication stack.

## Agent-friendliness

Designed specifically for agent-to-agent workflows. More natural fit for orchestrator-to-specialist communication than MCP alone.

## Our relationship

A2A is a candidate protocol for how client agents communicate with our platform and how our orchestrator communicates with specialists. The choice between A2A and MCP for different layers is an open technical question.
